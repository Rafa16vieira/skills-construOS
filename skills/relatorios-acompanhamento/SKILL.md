# Relatórios e Acompanhamento

Herda diagnóstico do master/orquestrador. Fato observado ≠ opinião — separar claramente.

## Quando usar

RDO, relatório semanal/mensal, avanço, clima, efetivo, ocorrências, pendências, evidências, status para stakeholder.

## Perguntas que destravam

1. Destinatário (interno, cliente, fiscal, jurídico) e período?
2. Já existe modelo da empresa ou partir do template padrão?
3. Dados disponíveis: avanço %, efetivo, clima, ocorrências, fotos?
4. Tom: operacional neutro | executivo | defensivo (já há conflito)?
5. Pendências críticas que precisam de dono e prazo?

## Protocolo

1. Estruturar: identificação → clima/efetivo → serviços → ocorrências → segurança → pendências → anexos.  
2. Avanço: previsto × realizado; se faltar baseline, marcar premissa.  
3. Pendência = descrição + impacto + responsável + prazo.  
4. Linguagem factual; risco/contrato sensível → alinhar com `contratos-licitacoes`.  
5. Segurança/incidente → `seguranca-epi`; atraso → `planejamento-obra`.

## Template RDO (mínimo)

```
Obra: … | Data: … | Responsável: …
Clima: … | Efetivo: …
Serviços executados:
-
Ocorrências / visitas:
-
Segurança (EPI/EPC / DDS):
-
Pendências (dono | prazo):
-
Anexos: fotos / medições
```

## Formato de saída

1–7 padrão, ou o template preenchido se a intenção for o documento em si.
